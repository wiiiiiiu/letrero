1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. O simplemente haz clic en este enlace para entrar:  
   👉 [Entrar al letrero LED](medng rik)
4. Configura:
   - Texto a mostrar.
   - Modo de color (mono/multi).
   - Color principal.
   - Cantidad de colores (solo multicolor).
   - Velocidad del desplazamiento.
   - Tamaño de letra.
5. Presiona **Start** y disfruta del efecto LED.
